# EmpireCommunity

**Comunidade de jogos e tecnologia, desde 2022.**

[![Discord](https://img.shields.io/badge/Discord-Entrar-5865F2?style=for-the-badge&logo=discord&logoColor=white)](https://discord.gg/7Pxg3gyr8n)

</div>

A EmpireCommunity existe para que ninguém precise jogar sozinho. Reunimos quem gosta de jogos e de tecnologia em um ambiente amigável e mantemos servidores para que cada pessoa possa entrar no mundo quando quiser, de graça, com o apoio de doações voluntárias.

Tudo começou em 20 de agosto de 2022, com um servidor no Discord. Hoje mantemos servidores de Minecraft com modpacks, e o acesso se dá pelo Discord. Aqui no GitHub ficam os bots, as ferramentas e os jogos que a comunidade constrói.

*[Read in English](#in-english)*

## Projetos

### EmpireMuse

| Repositório | O que é |
| :--- | :--- |
| [EmpireMuse](https://github.com/EmpireCommunity/EmpireMuse) | Bot de música para Discord, gratuito e de código aberto, com player interativo, comandos de barra, vários bots em conjunto, Last.fm e painel web em [muse.empirecommunity.org](https://muse.empirecommunity.org). Python, disnake e Lavalink. |
| [EmpireMuse-RPC-app](https://github.com/EmpireCommunity/EmpireMuse-RPC-app) | Aplicativo de desktop que mostra no seu perfil do Discord a música tocando no bot. |

## In English

EmpireCommunity exists so that no one has to play alone. We bring together people who enjoy games and technology in a friendly environment, and we keep servers running so that anyone can enter the world whenever they want, for free, with the support of voluntary donations.

Most of the community is Brazilian, so day-to-day conversation happens in Portuguese. [Discord](https://discord.gg/7Pxg3gyr8n) is also the channel for contact, support and collaboration in English. Issues and pull requests are welcome in either language: start with the [contributing guide](https://github.com/EmpireCommunity/.github/blob/main/CONTRIBUTING.md), and please report vulnerabilities privately, as the [security policy](https://github.com/EmpireCommunity/.github/blob/main/SECURITY.md) explains.
